# TProgramming_2025 - Task 3

Яшков Иван Александрович, 2/198

Лабораторная: вычисление функции

`y = sqrt((a + b*x) / lg(x)^3)`

Параметры:
- `a = 7.2`
- `b = 1.3`
- задача A: `x` от `1.56` до `4.71` с шагом `0.63`
- задача B: `x = 2.4, 2.8, 3.9, 4.7, 3.16`

Реализовано:
- проверка ОДЗ (`x > 0`);
- обработка ошибок вычисления;
- вывод результатов для задачи A и B.
